# Local LLM Quiz Generator

A local LLM-powered quiz generator that creates multiple-choice
questions from user-provided topics.

## Tech Stack

- Python
- Ollama
- Gemma
- Streamlit

## Planned Features

- Generate quizzes from a topic
- Select difficulty
- Generate multiple-choice questions
- Provide answers and explanations
- Automatically calculate quiz scores
